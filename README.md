# TaskFlow

Small TypeScript + Express project used to demonstrate professional programming terminology.

## Concepts demonstrated

- codebase
- feature
- bug
- runtime
- dependency
- coupling
- cohesion
- refactoring
- deployment
- technical debt

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm test
npm run check
```

## Recording notes

The files under `src/examples/` contain intentionally simplified before/after examples for coupling, cohesion and refactoring. `src/utils/price.ts` is intentionally buggy for the bug demonstration.
